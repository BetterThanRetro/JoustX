JoustX: Williams Joust (1982) arcade game source code in C#

JoustX is the 1982 Williams arcade game Joust, rebuilt as native C#. Nothing emulates the game's processors, yet it plays identically to the original, frame by frame.

Read the source code on GitHub

This site holds no playable game and no ROM files. The project is published as source only, for preservation.

What it is

  • The main board's 6809 program (9,696 instructions) and the sound board's 6808 program (1,376 instructions) as C#. The hot paths are written by hand and the rest is translated from the original source.
  • A C# assembler that builds all 12 main-board ROM images from the original assembly source and checks them against the game's own checksum table.
  • A desktop app and a WebAssembly browser version, with an optional high-definition picture over the same untouched game logic.

How it stays faithful

The original program runs on a C# reference machine, which serves as the ground truth. Every hand-written routine is compared with the original, per call, on registers, flags, cycle counts and memory writes. Whole games are then played on both side by side and compared on every frame, and the sound output matches sample for sample.

Build it yourself

With the .NET 10 SDK and a copy of the repository:

dotnet run --project src/Joust.App

The game is assembled from the original source at start-up, so no ROM files are needed. The README explains the browser build and the verification tools.

Where it comes from

  1. Williams Electronics, 1982: designed by John Newcomer and programmed by Bill Pfutzenreuter, Cary Kolker and Ken Lantz, with the sound ROM by John Kotlarik and Tim Murphy.
  2. historicalsource/joust: the original source, published.
  3. synamaxmusic/joust: SynaMax's rewrite for a modern assembler, which rebuilds every ROM exactly.
  4. JoustX: the same program as C#.
